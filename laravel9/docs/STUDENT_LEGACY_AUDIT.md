## Что намеренно не копируется 1:1

- Небезопасная выдача файлов через прямые публичные пути — заменена контроллерами с авторизацией.
- `mail()` из `gml.php` — заменён Laravel Mail и журналом отправок.
- Legacy XML/HTML-парсеры не используются для новых попыток; для новых тестов хранится нормализованный snapshot результата.
- Старые fake-Word HTTP headers отчётов не воспроизводятся; используется печатная HTML/PDF-совместимая форма.

## Остаточные проверки перед production

1. Выполнить `php artisan migrate`.
2. Повторно запустить `php artisan legacy:import-nmo-quiz-state` — команда теперь синхронизирует mapped NMO-прогресс с пользовательским кабинетом.
3. Проверить MAIL_* конфигурацию и тестовую рассылку на 1 программе.
4. Smoke-test на копии реальной БД: вход → программа → материал → тест → разбор результата → практика → итоговая → завершение → документ.
5. Проверить несколько старых NMO-пользователей, у которых `tm_nmo_razd_user.proydeno=1`, что prerequisites и процент программы отображаются корректно.

## Вывод

После этого прохода известных бизнес-функций legacy-пользовательского кабинета без Laravel-эквивалента не осталось. Оставшиеся риски относятся к фактическим данным конкретной legacy-БД, старым нестандартным пакетам/файлам и runtime-конфигурации окружения, а не к отсутствующей пользовательской бизнес-логике.

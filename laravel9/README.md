# ZMUDPO — Laravel 9

Новая версия системы ДПО. Старый код в корне репозитория не изменяется; новая система разрабатывается в каталоге `laravel9/`.

## Цели переноса

- сохранить функции действующей системы ДПО/НМО;
- перенести прямые SQL-запросы и PHP-страницы на MVC Laravel 9;
- единая авторизация для слушателей, кураторов и администраторов;
- сохранить `legacy_id` для безопасной миграции существующей БД;
- современный адаптивный интерфейс;
- журналирование действий, безопасные пароли, CSRF и middleware ролей;
- поэтапный импорт старых данных из отдельного подключения `legacy`.

## Основные модули

1. Слушатели, группы и образовательные программы.
2. ДПО и НМО: разделы, учебные материалы, прогресс.
3. Тесты, вопросы, попытки и результаты.
4. Практика, дневники, задания и контрольные/итоговые работы.
5. Документы, удостоверения, сертификаты и архив.
6. Форум, объявления, сообщения слушатель ↔ куратор.
7. Кабинет куратора: контроль прогресса, проверка работ, статистика.
8. Администрирование пользователей, программ, контента и справочников.

## Запуск

```bash
cd laravel9
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```

Для импорта старой БД заполните `LEGACY_DB_*` в `.env`, затем:

```bash
php artisan legacy:import --core
```

Подробная карта соответствия старых страниц и новых модулей — в `docs/LEGACY_PARITY.md`.
